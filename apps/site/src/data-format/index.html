The Landscape Package

One JSON file carries a woodlot's corridor layers between the mapping workspace, VergeCommon and your own tools. Lengths are meters and areas are square meters. Coordinates are WGS84 longitude and latitude.

Layers

LayerGeometryProperties that matter
coreAreasPolygondfm_id; core_class: old-growth-candidate, old-growth-verified (needs evidence_id), riparian-core or reserve; optional temp_c for climate routes
retainedPolygonRetained forest: riparian buffers, corridors, retained stands; optional stand_age in years for projections
roadsLine or polygonwidth_m for a centerline, or the package's roadWidthM
waterPolygonOpen water; buffer stream centerlines into polygons first
crossingsPointpassage: verified, assumed or none
treatmentsPolygondfm_id, period, intensity; inside a corridor only with corridor_permitted, a light intensity and a reason
boundaryPolygonOutline of the planning area; carried for reference, not used by the check
parcelsPolygonconsent: covered or none; corridor on covered parcels counts as committed. Optional consent_year for when consent began, or planned_year for a parcel expected to join
streamsLineOptional, for the old-growth spine: dfm_id and stream_order, the Strahler order from 1 to 12
connectorsLineOptional, for the old-growth spine: dfm_id and kind: ridge, valley or saddle

A package without streams or connectors reads exactly as before, with the same checksum.

Parameters

Every width, age and temperature that changes a result is recorded with its source, so a reviewer can see where it came from.

ParameterUsed byMeaning
minWidthM, minWidthSourceEvery checkThe minimum corridor width and why it was chosen. Required.
roadWidthMEvery checkWidth of road centerlines that have no width_m of their own
pinchFractionEvery checkLinks narrower than the minimum plus this share are flagged as pinch points. Default 0.1
spineWidthByOrderM, spineWidthSourceSpineCorridor width by stream order, for example {"1": 115, "2": 140, "3": 180}. Each is at least the minimum and never narrower for a larger river
connectorWidthM, connectorWidthSourceSpineWidth of ridge, valley and saddle links
junctionSnapMSpineA line that ends within this distance of another joins it. Default 5, at most 10
disturbanceWidthMSpineWidth of the single disturbance the network is tested against. Default: the widest corridor plus 2 m
ageAsOfYearProjectionsThe year stand ages and consent are recorded for
oldGrowthAgeYears, oldGrowthAgeSourceProjectionsThe stand age at which retained forest counts as old enough. Age is not condition
milestoneYearsProjectionsUp to 12 years to project, from ageAsOfYear on
coreTempSourceClimate routesWhere the cores' temp_c values come from, such as a 30-year climate normal
climateWarmingC, climateSourceClimate routesThe warming to plan for: a route must reach a core at least this much cooler

A minimal package

{
  "dfm_package": "1.0",
  "crs": "EPSG:4326",
  "units": { "length": "m", "area": "m2" },
  "params": {
    "minWidthM": 100,
    "minWidthSource": "Co-op woodland policy, section 4",
    "roadWidthM": 6
  },
  "sources": { "roads": { "title": "County road centerlines", "date": "2026-05-01" } },
  "layers": { "coreAreas": [], "retained": [], "roads": [], "water": [],
              "crossings": [], "treatments": [], "parcels": [], "boundary": [] }
}

Run the check with the open-source dfm-core package. It is not on npm yet; install it from the repository until it is published.

import { checkConnectivity, fromLandscapePackage } from '@viridis/dfm-core';
const result = await checkConnectivity(fromLandscapePackage(pkg));
// result.status is 'pass', 'fail' or 'incomplete', with reasons

The old-growth spine

Five functions work from the same package. Each returns ok or incomplete with reasons, records its engine version and an input checksum, and states its limits.

import { deriveSpine, spineNetwork, projectSpine,
         climateRoutes, buildOutFrontier } from '@viridis/dfm-core';
const input = fromLandscapePackage(pkg);
const draft = deriveSpine(input);     // corridors along streams and links
const network = spineNetwork(input);  // links, loops, single points of failure
// A steward reviews the draft, records stand_age on each piece
// and saves it as retained forest:
const plan = { ...input, retained: draft.features };
const outlook = projectSpine(plan);   // committed and old-age links by year
const routes = climateRoutes(plan);   // linked routes toward cooler cores
const next = buildOutFrontier(plan);  // woodlots that would extend the spine

Projections assume no fire, storm or new road, and use ages and join years as recorded. Climate routes use the temperatures you supply. Neither predicts what species will do.
